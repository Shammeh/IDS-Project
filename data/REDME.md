# Data

This project uses the **UNSW-NB15** dataset (Australian Centre for Cyber Security, UNSW Canberra).

Download the four CSV files (`UNSW-NB15_1.csv` to `UNSW-NB15_4.csv`) and the feature description file from the official page:
https://research.unsw.edu.au/projects/unsw-nb15-dataset

Place them in this folder:

```
data/
├── UNSW-NB15_1.csv
├── UNSW-NB15_2.csv
├── UNSW-NB15_3.csv
└── UNSW-NB15_4.csv
```

The CSV files are not committed because of their size.
